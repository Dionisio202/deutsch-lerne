## 5. Diálogo completo de ejemplo

> **Kellner:** *Guten Tag! Was möchten Sie trinken?*  
> **Edison:** *Ich hätte gern ein Wasser, bitte.*  
> **Kellner:** *Mit oder ohne Kohlensäure?*  
> **Edison:** *Mit Kohlensäure, bitte.*  
> **Kellner:** *Und zum Essen?*  
> **Edison:** *Ich nehme die Pizza Margherita.*  
> **Kellner:** *Sehr gern. Möchten Sie auch einen Salat?*  
> **Edison:** *Nein, danke.*  
>  
> *(Después...)*  
>  
> **Edison:** *Die Rechnung, bitte.*  
> **Kellner:** *Das macht 12,50 Euro.*  
> **Edison:** *Hier sind 15 Euro. Stimmt so.*  
> **Kellner:** *Vielen Dank!*

## 6. Verbos de comida y bebida

| Verbo | Significado | Ejemplo |
| :--- | :--- | :--- |
| **essen** | comer | *Ich esse Brot.* |
| **trinken** | beber | *Sie trinkt Wasser.* |
| **kochen** | cocinar | *Wir kochen Suppe.* |
| **bestellen** | pedir | *Ich bestelle Pizza.* |
| **bezahlen** | pagar | *Ich bezahle die Rechnung.* |
| **schmecken** | saber a / gustar | *Das schmeckt gut!* |
| **mögen** | gustar (general) | *Ich mag Fisch.* |
| **probieren** | probar | *Probieren Sie das!* |

### ⚠️ *essen* es irregular

| ich | esse |
| du | **isst** |
| er/sie/es | **isst** |
| wir | essen |
| ihr | esst |
| sie/Sie | essen |

## 7. Adjetivos para comida

| Alemán | Español |
| :--- | :--- |
| **lecker** | rico / sabroso |
| **gut** | bueno |
| **süß** | dulce |
| **sauer** | ácido |
| **salzig** | salado |
| **scharf** | picante |
| **bitter** | amargo |
| **frisch** | fresco |
| **kalt** | frío |
| **heiß** | muy caliente |
| **warm** | caliente |

### Ejemplos

> *Die Suppe ist **lecker**!* (¡La sopa está rica!)  
> *Das ist zu **scharf** für mich.* (Esto es demasiado picante para mí.)  
> *Der Kaffee ist **kalt**.* (El café está frío.)

## 10. Errores típicos

> ❌ *Ich **bin** Hunger.*  
> ✅ *Ich **habe** Hunger.*  
> *(En alemán "tener hambre", no "estar hambriento".)*

> ❌ *Ich esse **das** Pizza.*  
> ✅ *Ich esse **die** Pizza.* / *Ich esse Pizza.*  
> *(Pizza es femenina.)*

> ❌ *Wir wollen **eins** Bier.*  
> ✅ *Wir möchten **ein** Bier.*  
> *(Para pedir en restaurante: möchten, no wollen.)*
