### Modificadores de color

| Alemán | Significado | Ejemplo |
| :--- | :--- | :--- |
| **hell-** | claro | *hellblau* (azul claro) |
| **dunkel-** | oscuro | *dunkelgrün* (verde oscuro) |

> ⚠️ Se escriben **juntos**: *hellrot, dunkelblau, hellgrau, dunkelbraun*.

## 2. ¿Cómo preguntar por colores?

| Pregunta | Significado |
| :--- | :--- |
| **Welche Farbe hat...?** | ¿De qué color es...? |
| **Welche Farbe magst du?** | ¿Qué color te gusta? |
| **Was ist deine Lieblingsfarbe?** | ¿Cuál es tu color favorito? |

### Respuestas

> *Das Auto ist **rot**.* (El auto es rojo.)  
> *Meine Lieblingsfarbe ist **blau**.* (Mi color favorito es el azul.)  
> *Ich mag **grün** und **schwarz**.* (Me gusta el verde y el negro.)

## 4. Verbos de ropa

| Verbo | Significado | Ejemplo |
| :--- | :--- | :--- |
| **tragen** | llevar puesto | *Ich trage Jeans.* |
| **anziehen** *(sep)* | ponerse | *Ich ziehe einen Pullover an.* |
| **ausziehen** *(sep)* | quitarse | *Sie zieht die Jacke aus.* |
| **kaufen** | comprar | *Er kauft ein Hemd.* |
| **anprobieren** *(sep)* | probarse | *Ich probiere die Hose an.* |
| **passen** *(+ Dat)* | quedar bien (talla) | *Die Hose passt mir.* |
| **stehen** *(+ Dat)* | quedar bien (apariencia) | *Die Farbe steht dir.* |
| **gefallen** *(+ Dat)* | gustar | *Das Kleid gefällt mir.* |

> ⚠️ ***tragen* es irregular:** ich trage, du **trägst**, er/sie/es **trägt** (con Umlaut).

## 5. En la tienda de ropa

### Frases del cliente

| Alemán | Español |
| :--- | :--- |
| *Ich suche eine Jacke.* | Estoy buscando una chaqueta. |
| *Haben Sie das in Größe M?* | ¿Lo tiene en talla M? |
| *Kann ich das anprobieren?* | ¿Puedo probarme esto? |
| *Wo ist die Umkleidekabine?* | ¿Dónde está el probador? |
| *Es ist zu klein / zu groß.* | Es demasiado pequeño/grande. |
| *Es passt mir nicht.* | No me queda bien. |
| *Was kostet das?* | ¿Cuánto cuesta? |
| *Ich nehme das.* | Me lo llevo. |

## 6. Tallas (Größen)

| Tamaño | Alemán | Abreviatura |
| :---: | :--- | :---: |
| Pequeño | klein | **S** |
| Mediano | mittel | **M** |
| Grande | groß | **L / XL** |

> 💡 **Para zapatos** se usan números europeos (38, 40, 42…) igual que en España y Ecuador.

## 7. Diálogo completo de ejemplo

> **Verkäuferin:** *Guten Tag! Kann ich Ihnen helfen?*  
> **Edison:** *Ja, ich suche eine Jeans.*  
> **Verkäuferin:** *Welche Größe haben Sie?*  
> **Edison:** *Größe M, bitte. Haben Sie die in **schwarz**?*  
> **Verkäuferin:** *Ja, hier ist sie. Möchten Sie sie **anprobieren**?*  
> **Edison:** *Ja, gerne. Wo ist die Umkleidekabine?*  
> **Verkäuferin:** *Da hinten.*  
>  
> *(Después...)*  
>  
> **Edison:** *Die Jeans **passt** mir gut.*  
> **Verkäuferin:** *Sie **steht** Ihnen auch sehr gut.*  
> **Edison:** *Was **kostet** sie?*  
> **Verkäuferin:** *59,99 Euro.*  
> **Edison:** *Gut, ich **nehme** sie.*

## 8. Combinaciones útiles: ropa + color

| Estructura | Ejemplo |
| :--- | :--- |
| *ein/eine + color + ropa* | *eine **rote** Jacke* (una chaqueta roja) |
| *meine + color + ropa* | *mein **blaues** T-Shirt* |
| *Ich trage + color + ropa* | *Ich trage **schwarze** Schuhe.* |

> ⚠️ **Cuando el color va DELANTE del sustantivo, sí se declina.** Esa es la pesadilla del A2. En A1 puedes simplificar diciendo:
> - *Die Jacke ist **rot**.* (predicativo, sin declinar) ✅
> - En lugar de: *Ich habe **eine rote** Jacke.*

---

## 9. Frases típicas con ropa y color

> *Ich trage heute eine **blaue** Hose.* (Hoy llevo un pantalón azul.)  
> *Mein Lieblingspulli ist **schwarz**.* (Mi suéter favorito es negro.)  
> *Die Schuhe sind **zu klein**.* (Los zapatos me quedan demasiado pequeños.)  
> *Das Kleid **steht dir** sehr **gut**.* (El vestido te queda muy bien.)  
> *Welche Farbe **magst** du?* (¿Qué color te gusta?)

---

## 10. Errores típicos

> ❌ *Ich **trägt** ein T-Shirt.*  
> ✅ *Ich **trage** ein T-Shirt.*  
> *(tragen es irregular: er **trägt**, pero ich **trage**.)*

> ❌ *Das T-Shirt ist **rotes**.*  
> ✅ *Das T-Shirt ist **rot**.*  
> *(Predicativo: el color no se declina.)*

> ❌ *Die Hose **passt mich**.*  
> ✅ *Die Hose **passt mir**.*  
> *(passen rige Dativ, no Akkusativ.)*
