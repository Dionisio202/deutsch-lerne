## 1. Las preguntas clave sobre trabajo

| Pregunta | Significado |
| :--- | :--- |
| **Was sind Sie von Beruf?** | ¿Cuál es su profesión? (formal) |
| **Was machst du beruflich?** | ¿En qué trabajas? (informal) |
| **Wo arbeiten Sie?** | ¿Dónde trabaja? |
| **Was machst du?** | ¿Qué haces? (de trabajo) |

### Respuestas tipo

> *Ich bin **Lehrer**.* (Soy profesor.)  
> *Ich arbeite als **Programmierer**.* (Trabajo como programador.)  
> *Ich arbeite in **einer Bank**.* (Trabajo en un banco.)  
> *Ich bin **Student / Studentin**.* (Soy estudiante.)

> ⚠️ **REGLA DE ORO:** Las profesiones con *sein* van **SIN artículo**.  
> *"Soy un médico"* → *Ich bin Arzt.* ❌ ~~Ich bin ein Arzt~~

> 💡 **El patrón general:** El femenino se forma agregando **-in** al masculino. *Lehrer → Lehrerin* (el plural femenino es *Lehrerinnen*).

## 3. Verbos sobre trabajo

| Verbo | Significado | Ejemplo |
| :--- | :--- | :--- |
| **arbeiten** | trabajar | *Ich arbeite bei Siemens.* |
| **studieren** | estudiar (universidad) | *Sie studiert Medizin.* |
| **lernen** | estudiar / aprender | *Er lernt einen Beruf.* |
| **verdienen** | ganar (dinero) | *Ich verdiene 2000 Euro.* |
| **suchen** | buscar | *Ich suche eine Arbeit.* |
| **finden** | encontrar | *Sie hat eine Stelle gefunden.* |

---

## 4. Preposiciones para hablar del trabajo

| Preposición | Uso | Ejemplo |
| :--- | :--- | :--- |
| **bei** + Dativ | empresa | *Ich arbeite **bei** Google.* |
| **in** + Dativ | lugar / sector | *Ich arbeite **in** einem Büro.* |
| **als** + nominativo | función | *Ich arbeite **als** Programmierer.* |
| **für** + Akk | cliente | *Ich arbeite **für** einen Kunden.* |

## 5. Lugares de trabajo

| Alemán | Español |
| :--- | :--- |
| **das Büro** | la oficina |
| **die Firma** | la empresa |
| **das Geschäft / der Laden** | la tienda |
| **die Fabrik** | la fábrica |
| **das Krankenhaus** | el hospital |
| **die Schule** | la escuela |
| **die Universität / die Uni** | la universidad |
| **das Restaurant** | el restaurante |
| **die Bank** | el banco |
| **die Werkstatt** | el taller |
| **die Baustelle** | la obra |

### Ejemplos

> *Ich arbeite **im Büro**.* (Trabajo en la oficina.)  
> *Sie arbeitet **in einem Krankenhaus**.* (Trabaja en un hospital.)  
> *Wir arbeiten **bei einer Firma**.* (Trabajamos en una empresa.)

## 6. Adjetivos para describir el trabajo

| Alemán | Español |
| :--- | :--- |
| **interessant** | interesante |
| **langweilig** | aburrido |
| **anstrengend** | exigente / pesado |
| **stressig** | estresante |
| **leicht** | fácil |
| **schwer** | difícil / pesado |
| **gut bezahlt** | bien pagado |
| **schlecht bezahlt** | mal pagado |
| **kreativ** | creativo |
| **monoton** | monótono |

### Ejemplos

> *Mein Job ist **interessant** aber **anstrengend**.* (Mi trabajo es interesante pero exigente.)  
> *Die Arbeit ist **gut bezahlt**.* (El trabajo está bien pagado.)

---

## 7. Estructura completa para hablar de tu trabajo

> *Ich bin **Programmierer von Beruf**. Ich arbeite **bei einer Firma** in **Quito**. Mein Job ist **interessant**, aber manchmal **stressig**. Ich arbeite von **Montag bis Freitag**, **von 9 bis 18 Uhr**. Ich **verdiene gut** und mag meine Kollegen. **Am Wochenende habe ich frei**.*

> *(Soy programador. Trabajo en una empresa en Quito. Mi trabajo es interesante, pero a veces estresante. Trabajo de lunes a viernes, de 9 a 18. Gano bien y me gustan mis colegas. Los fines de semana descanso.)*

## 9. Frases típicas en el trabajo

| Frase | Significado |
| :--- | :--- |
| *Ich bin selbstständig.* | Soy autónomo / freelance. |
| *Ich arbeite Vollzeit.* | Trabajo a tiempo completo. |
| *Ich arbeite Teilzeit.* | Trabajo a tiempo parcial. |
| *Ich mache eine Ausbildung.* | Hago una formación profesional. |
| *Ich suche eine Stelle.* | Estoy buscando trabajo. |
| *Ich bin arbeitslos.* | Estoy desempleado. |
| *Ich gehe in Rente.* | Me jubilo. |

---

## 10. Errores típicos

> ❌ *Ich bin **ein** Lehrer.*  
> ✅ *Ich bin Lehrer.*  
> *(Profesiones SIN artículo después de sein.)*

> ❌ *Ich arbeite **in** Siemens.*  
> ✅ *Ich arbeite **bei** Siemens.*  
> *(Para empresas se usa **bei**, no in.)*

> ❌ *Meine Mutter ist **Doktorin**.*  
> ✅ *Meine Mutter ist **Ärztin**.*  
> *(En alemán "médica" es Ärztin, no Doktorin. Doktor solo se usa para el título académico.)*
