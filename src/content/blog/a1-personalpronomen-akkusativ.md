## 1. ¿Para qué sirven los pronombres en Akkusativ?

Cuando ya mencionaste algo o alguien, no quieres repetir el sustantivo completo cada vez. En español dices "lo veo" en vez de "veo a Pedro". En alemán pasa igual: usas un **pronombre en Akkusativ** para reemplazar el objeto directo.

> *Ich sehe **Peter**.* (Veo a Peter.)  
> ↓  
> *Ich sehe **ihn**.* (Lo veo.)

---

## 2. La tabla completa

Cada pronombre personal del Nominativ tiene su versión Akkusativ. Aquí están emparejados:

| Nominativ | <span style="color: #3b82f6; font-weight: bold;">Akkusativ</span> | Significado |
| :---: | :---: | :--- |
| **ich** | <span style="color: #3b82f6; font-weight: bold;">mich</span> | me / a mí |
| **du** | <span style="color: #3b82f6; font-weight: bold;">dich</span> | te / a ti |
| **er** | <span style="color: #3b82f6; font-weight: bold;">ihn</span> | lo / a él |
| **sie** (ella) | <span style="color: #ef4444; font-weight: bold;">sie</span> | la / a ella |
| **es** | <span style="color: #10b981; font-weight: bold;">es</span> | lo / a ello |
| **wir** | <span style="color: #3b82f6; font-weight: bold;">uns</span> | nos / a nosotros |
| **ihr** | <span style="color: #3b82f6; font-weight: bold;">euch</span> | os / a ustedes (informal) |
| **sie** (ellos) | <span style="color: #ef4444; font-weight: bold;">sie</span> | los / a ellos |
| **Sie** (Usted) | <span style="color: #9333ea; font-weight: bold;">Sie</span> | lo / a Usted (formal) |

> 💡 **La mayoría son nuevas formas.** Solo *sie* (ella, ellos) y *es* se mantienen iguales que en Nominativ. *Sie* (formal) también.

---

## 3. Cómo elegir el pronombre correcto

El género del pronombre depende del **género del sustantivo en alemán**, NO del español. Esto es muy importante:

| Sustantivo | Género | Pronombre Akk |
| :--- | :---: | :---: |
| *der Tisch* (la mesa) | masc | **ihn** |
| *die Lampe* (la lámpara) | fem | **sie** |
| *das Auto* (el auto) | neut | **es** |
| *der Stuhl* (la silla) | masc | **ihn** |
| *die Sonne* (el sol) | fem | **sie** |

> ⚠️ **Truco:** No pienses en español. Piensa en el artículo alemán:
> - *der* → *ihn*
> - *die* → *sie*
> - *das* → *es*

## 4. Ejemplos con todos los pronombres

| Pronombre | Ejemplo |
| :---: | :--- |
| **mich** | *Liebst du **mich**?* (¿Me amas?) |
| **dich** | *Ich liebe **dich**.* (Te amo.) |
| **ihn** | *Ich sehe **ihn** im Park.* (Lo veo en el parque.) |
| **sie** | *Kennst du **sie**?* (¿La conoces?) |
| **es** | *Wo ist das Buch? — Ich habe **es**.* (¿Dónde está el libro? — Lo tengo.) |
| **uns** | *Sie besuchen **uns** morgen.* (Nos visitan mañana.) |
| **euch** | *Ich frage **euch**.* (Os pregunto.) |
| **sie** (pl) | *Wir treffen **sie** heute.* (Los vemos hoy.) |
| **Sie** | *Ich rufe **Sie** an, Herr Müller.* (Lo llamo, Sr. Müller.) |

---

## 5. ¿Dónde van los pronombres en la oración?

La regla general en A1: el pronombre objeto va **inmediatamente después del verbo** (en oración afirmativa).

> *Ich **sehe ihn** im Park.*  
> *Wir **besuchen sie** morgen.*  
> *Sie **liebt mich**.*

Si hay un complemento de tiempo, lugar o modo, el pronombre va antes:

> *Ich sehe **ihn** heute im Park.* (Lo veo hoy en el parque.)  
> *Ich treffe **sie** am Montag.* (La veo el lunes.)

## 6. Pronombres con verbos comunes A1

| Verbo + Akkusativ | Pronombre | Ejemplo |
| :--- | :---: | :--- |
| **lieben** (amar) | dich | *Ich liebe dich.* |
| **brauchen** (necesitar) | dich | *Ich brauche dich.* |
| **anrufen** (llamar por tel.) | dich | *Ich rufe dich an.* |
| **besuchen** (visitar) | euch | *Wir besuchen euch.* |
| **kennen** (conocer) | ihn | *Ich kenne ihn.* |
| **verstehen** (entender) | dich | *Ich verstehe dich nicht.* |
| **suchen** (buscar) | sie | *Ich suche sie.* |
| **fragen** (preguntar) | ihn | *Ich frage ihn.* |
| **treffen** (encontrar) | euch | *Wir treffen euch um 8.* |

---

## 7. Errores típicos

> ❌ *Ich liebe **du**.*  
> ✅ *Ich liebe **dich**.*  
> *(Después de "lieben" siempre va Akkusativ.)*

> ❌ *Wo ist das Buch? — Ich habe **ihn**.*  
> ✅ *Wo ist das Buch? — Ich habe **es**.*  
> *(Das Buch es neutro, no masculino. En español dirías "lo tengo" pero en alemán "es".)*

> ❌ *Ich sehe **er**.*  
> ✅ *Ich sehe **ihn**.*

## 8. Truco para memorizar rápido

Asocia cada pronombre con una frase corta que repitas todos los días:

| Pronombre | Frase mnemónica |
| :---: | :--- |
| **mich** | *Liebst du mich?* |
| **dich** | *Ich liebe dich.* |
| **ihn** | *Ich sehe ihn.* |
| **sie** | *Ich kenne sie.* |
| **es** | *Ich habe es.* |
| **uns** | *Er besucht uns.* |
| **euch** | *Wir treffen euch.* |
| **Sie** | *Ich rufe Sie an.* |
